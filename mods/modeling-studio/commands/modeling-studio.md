---
name: modeling-studio
description: Place the Spawn 3D Modeling Studio on clear ground facing the spawn, then run any asks waiting in world.state.m3d.pending through the paint → 3D pipeline.
---

Load the `modeling-studio#modeling-studio` skill. Find the `modeling-studio` object; if it is missing, spawn it from `mods/modeling-studio/templates/studio.js#studio`. Look from the spawn point and move the studio root to clear, flat ground 6 m across, near the spawn, its open side (+Z) turned toward the player. Look at it to confirm the dais, canvas, pedestal and shelf stand on the ground. Read the world's ui.js (world.config.yaml `ui.render`); if it doesn't import `mods/modeling-studio/hud.js`, add `import * as modelingStudio from "<relative path>/mods/modeling-studio/hud.js"`, re-export its window hooks (`export { m3dPvDown, m3dPvWheel, m3dPvReset, m3dPvTool, m3dPvDraft, m3dPvEdit, m3dPvClear, m3dTkMeasure, m3dTkDown, m3dTkWheel, m3dTkReset, m3dMpvMove, m3dMpvSize, m3dDraft, m3dPose, m3dPick, m3dPreview, m3dUpload, m3dAsk, m3dClearRefs, m3dGuide } from "<relative path>/mods/modeling-studio/hud.js"`) and append `modelingStudio.render(ctx, player)` to the HTML the default render returns; look at the player screen to see the 🎨 3D studio button bottom-left. Then, for each row in `world.state.m3d.pending`, run the skill's pipeline. Tell the creator: open god mode's 🎨 Studio tab, or press M (the 🎨 3D studio button) without god mode in the build room; type an ask, press Paint or Build 3D.
