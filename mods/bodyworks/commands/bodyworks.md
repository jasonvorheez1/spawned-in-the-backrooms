description: Run BodyWorks on a rigged humanoid .glb: zones, cages, slots and collider capsules, with proof sheets.

Load the `bodyworks#bodyworks` skill and the workshop skill. Ask for the body (.glb, .gltf zip or .fbx) if none was named, fetch it into the workshop, then follow the skill's recipe in order: run `--stages inspect` first and stop at the first failed check. Read every proof sheet yourself before reporting. Report each layer's pass line, the slot list and every `review:` flag, then upload the exported glb and place it at the fitting room's front work spot.
