# BodyWorks (private)
Any rigged humanoid .glb → T0 zones, T1 cages, garment slots, T2 collision bubbles, one command.
Start at `skills/bodyworks.md` (or `/bodyworks`). Sections: `tools/bwlib/t0.py` (zones) · `t1.py` (cages) · `slots.py` (slots from cages) · `t2.py` (bubbles).
