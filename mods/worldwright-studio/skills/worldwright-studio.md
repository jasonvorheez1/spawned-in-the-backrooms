# Worldwright Studio

Early release, subject to change. Open god mode → WW Studio. The package owns its tab, inputs and behaviors; do not copy them into the host config or expose the shell to players. The player courier consumes authored output only.

Books → folders → cards → pages and sections are the underlying documents. Codex is the read-only build plan; Research holds prose. Sound Studio and Asset Studio use Projects → Types → Files; Sound Studio's Custom Instruments folder is not a project. Card Metadata selects the editor. Respect Save/Discard/Cancel and existing write/pen guards.

Core authoring does not require other mods. Absolute Cinema, Film Kit, Asset Library and Atmosphere Kitchen are optional, separately installed partners with WWS-owned soft adapters. Never add a hard import or auto-install a missing partner.

Read README.md for the descriptive About and current early-release limits. The broad camera-scene editor is unfinished. Asset editing depth varies; do not claim a complete Blender-like editor. Audio/file and touch paths need wider device acceptance. Advise independent exports for important work.

Runtime entries: app-shell.js owns the god seat; ui.js renders the tab; lib/editor-session.js fences document opening; lib/cards.js and lib/store.js own saved content; cinema-courier.js consumes playback. Bare lib/ paths resolve inside this package. For Codex notes load worldwright-codex: concept folders, independent part cards and full usable A3 pages. Use the existing focused skills for paper, cards, sound, assets and compile. Host ownership attestation remains host-specific; follow worldwright-maintenance for setup and ownership changes.

Ships empty: never seed the development world's Canon arrangement, source cards, samples of authored scenes or personal settings. The host-world reset used to prepare this package is not an install/update hook. Do not wipe anyone's data, install partners or publish on a request merely to open the studio.
