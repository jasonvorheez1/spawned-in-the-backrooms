Original distributed WAV bytes are retained. The CDN references end in `.mp3`, but contain the original WAV audio; reference hashes match the source bytes. Pitch labels follow measured scientific notation rather than the archive's octave naming.

Worldwright Studio selects recordings and applies playback gain, panning, envelopes and held-bow leveling. The bow-stop profile uses original exact-pitch short/held recordings, with no time stretching, looping or added sample layers. A shaped release is not claimed to be the untouched original tail.
