# Slate
The creator's tablet. Open it from the god-mode rail (🗂 Slate). Home has the apps: Planner, Loom, Players, Game, World and Camera. Drag the top edge to move it, pull the gold corner to resize, and ▁ folds it. Starts empty.

## Design system

Every Slate screen follows `docs/DESIGN-SYSTEM.md` (Slate OS HIG): spacing, type, depth, colour, motion and the do/don't rules. Read it before touching UI.
